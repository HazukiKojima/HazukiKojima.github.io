C++20 DirectX 12 / HLSL 海・空・雲の描画 飛行モデル / 敵AI GPU計測 / LOD C# Native AOT / JSON
GitHub ソースコード

基本情報

ジャンル： 3Dフライトアクション

開発環境： C++20 / DirectX 12 / HLSL / C#（Native AOT）

制作期間： 2026年6月 ～ 現在

制作形態： 個人制作

実装したゲーム内容

  • 紫電改の操縦と、機関砲による敵機との空戦
  • 目標選択・ロックオン・未来位置照準・ 誘導ミサイルによる対艦攻撃
  • 哨戒機の迎撃、空母攻撃、増援との交戦へ進むミッション
  • 戦闘HUD、着弾・撃破エフェクト、 字幕・音声付きのカメラ演出
  • タイトルから勝敗判定、再挑戦までのゲーム進行

技術・アピールポイント

  • RE:Doxを活用したC++／C#連携
    RE:DoxによるJSON処理を、C# Native AOTでDLL化したラッパー経由でC++から利用。 C++ヘッダーから設定バインディングと検証コードを自動生成し、型・メモリ配置の整合性を確認します。
  • 海・空・雲の描画表現
    HLSLで波の動きや視線角度に応じた反射を実装。 空・雲・海霧を組み合わせ、空戦の舞台を表現しました。
  • 描画の最適化・GPU計測
    雲の低解像度描画や艦船の3段階LODで描画負荷を軽減。 GPUタイムスタンプで各描画処理の時間を計測できます。
  • 調整しやすい設計
    描画などの基盤をEngine、ゲーム固有の処理をGameへ分離。 機体性能・AI・武器の設定はJSONで調整できる構成にしました。
